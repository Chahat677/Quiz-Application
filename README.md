🐾 Memory Card Game
📌 Overview

A fun and interactive Memory Card Game built with HTML, CSS, and JavaScript. Flip cards, match pairs, and try to finish the game in the least moves and time. Tracks your best time using localStorage.

✨ Features

Flip cards and match pairs

Timer and move counter

Tracks best score in browser storage

Restart and shuffle options

Responsive and mobile-friendly

🎮 How to Play

Open index.html in your browser.

Click on a card to flip it.

Match two identical cards to mark them as matched.

The game ends when all cards are matched.

Check moves, time, and best score at the end.
